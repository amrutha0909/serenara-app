# Serenara Mindfulness Meditation App

Welcome to the **Serenara Mindfulness Meditation App**, a web-based application designed to guide users through mindfulness meditation sessions and provide supportive advice via a chatbot. Built with a focus on simplicity and accessibility, this app integrates advanced AI technologies to enhance the meditation experience. The app is deployed on Vercel and is accessible to users worldwide.

## Overview

Serenara offers a serene digital space where users can practice meditation through guided sessions (Breathing, Bodyscan, and Gratitude) and engage with a compassionate chatbot for personalized advice on mindfulness, yoga, and stress management. The app leverages the Hugging Face API to generate unique meditation scripts and the Google Gemini API to power the chatbot, ensuring a dynamic and engaging experience.

## Features

- **Guided Meditation Sessions**:
  - Choose from three meditation types: **Breathing**, **Bodyscan**, and **Gratitude**.
  - Scripts are dynamically generated by the Hugging Face API (using the `distilgpt2` model) and fall back to pre-defined scripts if the API fails.
  - Text-to-speech functionality reads the meditation instructions aloud using the browser’s `SpeechSynthesis` API.
  - Background music can be toggled on/off with adjustable volume.
  - Tracks total meditation time using `localStorage`.

- **Chatbot Support**:
  - A therapist-style chatbot powered by the Google Gemini API (`gemini-1.5-flash` model).
  - Provides concise, bullet-point-style answers to questions about meditation, yoga, stress management, and mindfulness.
  - Maintains in-memory session context for a personalized experience (non-persistent across server restarts).
  - Features a white glow effect and blinking cursor for an engaging interface.

- **User Interface**:
  - Responsive design compatible with desktop and mobile devices.
  - Includes pages for login, signup, feedback, and the main dashboard.
  - Custom favicon for branding in browser tabs.

- **Data Management**:
  - Uses `localStorage` to store the username and total meditation time.
  - No persistent user data on the server (ideal for a lightweight prototype).

## Tech Stack

- **Frontend**:
  - **HTML**: Structure for all pages (dashboard, login, signup, feedback).
  - **CSS**: Custom styles in `styles.css` with animations from Animate.css.
  - **JavaScript**: Core logic in `script.js` for meditation, chatbot, and user interactions.

- **Backend**:
  - **Node.js**: Server runtime environment.
  - **Express**: Web framework for handling API requests.
  - **Vercel**: Serverless deployment platform.

- **APIs and Integrations**:
  - **Hugging Face API**: Generates meditation scripts using the `distilgpt2` model.
  - **Google Gemini API**: Powers the chatbot with the `gemini-1.5-flash` model.

- **Other Tools**:
  - **SpeechSynthesis API**: Native browser API for text-to-speech.
  - **localStorage**: Browser storage for user data.
  - **Git**: Version control with GitHub.
  - **npm**: Package management for dependencies.
